# Functional Requirements for TODO App

1. User can add new TODO items.
2. User can view a list of all TODO items.
3. User can mark TODO items as completed.
4. User can delete TODO items.
5. User can edit the text of existing TODO items.
6. User can filter TODO items by status (all, active, completed).
7. User can clear all completed TODO items.
8. The app should persist TODO items between sessions (e.g., using local storage or a backend API).
9. The app should provide feedback for actions (e.g., confirmation for deletion, error messages).
10. The app should be responsive and usable on both desktop and mobile devices.
